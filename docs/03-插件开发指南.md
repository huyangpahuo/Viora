# 03 · 插件开发指南

> 目标:从零做出一个 Viora 风格插件,本地测试通过后发布到官方市场。

## 0. 概念

- 一个插件 = 一个文件夹:`plugin.json`(清单)+ 入口 DLL(可带附属 DLL);
- 插件在初始化时向宿主**注册能力**:风格预设(`convert.preset`)、导出格式(`export.format`)、界面文案(`localization.strings`);
- 插件运行在**可收集的独立 AssemblyLoadContext** 里,崩溃不会拖垮宿主;卸载即删文件夹。

## 1. 建项目

```bash
dotnet new classlib -n MyStyle -f net8.0
cd MyStyle
dotnet add package Viora.PluginSdk   # 发布到 NuGet 后;当前可先直接引用 src/Viora.PluginSdk 工程
```

csproj 里把 SDK 与 Core 标记为不随插件打包(宿主会提供):

```xml
<ItemGroup>
  <ProjectReference Include="..\src\Viora.PluginSdk\Viora.PluginSdk.csproj"
                    Private="false" ExcludeAssets="runtime" />
</ItemGroup>
```

## 2. 入口类(约 30 行)

```csharp
using Viora.Core.Plugins;
using Viora.PluginSdk;

namespace MyStyle;

public sealed class MyStylePlugin : VioraPluginBase
{
    private static readonly PluginMetadata Metadata = new(
        Id: "yourname.my-style",                 // 全局唯一,发布后不可改
        DisplayName: "My Style",
        Version: new Version(1, 0, 0),
        Author: "yourname",
        Description: "One-line description.",
        Homepage: null,
        Repository: new Uri("https://github.com/yourname/my-style"),
        RequiredHostVersion: VersionRange.Any,
        Capabilities: new[] { "convert.preset" },
        Dependencies: Array.Empty<PluginDependency>());

    public MyStylePlugin() : base(Metadata) { }

    public override Task InitializeAsync(IPluginContext context, CancellationToken ct)
    {
        context.RegisterPreset(new MyStylePreset());
        return Task.CompletedTask;
    }
}
```

## 3. 实现风格预设

```csharp
using Viora.Core.Pipeline;

public sealed class MyStylePreset : IStylePreset
{
    public string Id => "yourname.my-style";                 // 预设键(作品库引用)
    public string DisplayNameKey => "Preset.MyStyle.Name";   // 本地化键(见第 5 步)
    public string DescriptionKey => "Preset.MyStyle.Description";
    public string? IconGlyph => null;

    public IReadOnlyList<IPresetParameter> Parameters { get; } = new IPresetParameter[]
    {
        new PresetParameter("intensity", "Param.Generic.Intensity", 0.6, 0.0, 1.0, 0.05),
        new PresetParameter("size",      "Param.Generic.Size",     8,   2,   64,  1),
    };

    public IReadOnlyList<IImageProcessingStage> BuildPipeline(
        IReadOnlyDictionary<string, object> parameters)
    {
        return new IImageProcessingStage[]
        {
            new MyQuantizeStage(),   // 你的处理阶段:实现 IImageProcessingStage
            new MyEdgeStage(),
        };
    }
}
```

- 参数键用 `Param.*` 系列既有键可直接复用现成翻译;新参数在语言包里加 `Param.YourKey` 与 `Param.YourKey.Description`;
- 阶类(Stage)接收 `ImageProcessingContext`(像素缓冲 + 参数),对 `buffer.Pixels` 做处理;参考 `src/Viora.Features/Convert.Styles` 任意一个风格的写法。

## 4. plugin.json 清单

```json
{
  "id": "yourname.my-style",
  "displayName": "My Style",
  "version": "1.0.0",
  "author": "yourname",
  "description": "One-line description.",
  "requiredHostVersion": "*",
  "entryAssembly": "MyStyle.dll",
  "typeName": "MyStyle.MyStylePlugin",
  "capabilities": [ "convert.preset" ],
  "dependencies": []
}
```

## 5. 界面文案(可选)

初始化时注册,键加 `lang::` 前缀:

```csharp
context.RegisterStrings(new Dictionary<string, string>
{
    ["zh-Hans::Preset.MyStyle.Name"] = "我的风格",
    ["en::Preset.MyStyle.Name"] = "My Style",
    ["zh-Hans::Preset.MyStyle.Description"] = "…",
    ["en::Preset.MyStyle.Description"] = "…",
});
```

## 6. 本地测试

1. Release 构建:`dotnet build -c Release`;
2. 把 `bin/Release/net8.0/**`(DLL + plugin.json)放进
   `<Viora.exe 旁>\plugins\yourname.my-style\`;
3. 启动 Viora:风格化页面出现你的风格卡片即成功;日志 `plugins\<id>` 有加载记录。

## 7. 发布到官方市场

1. 打包 zip:内容为**文件夹内容**(plugin.json 在 zip 根部),命名 `<id>.zip`;
2. Fork [huyangpahuo/Viora-plugins](https://github.com/huyangpahuo/Viora-plugins);
3. 把 zip 放进 `packages/`,在 `registry.json` 的 `presets` 数组追加条目:

```json
{
  "pluginId": "yourname.my-style",
  "presetId": "yourname.my-style",
  "name": { "zh": "我的风格", "en": "My Style" },
  "author": "yourname",
  "category": "Style.Cat.Experimental",
  "version": "1.0.0",
  "package": "packages/yourname.my-style.zip",
  "repository": "https://github.com/yourname/my-style",
  "tags": ["示例"],
  "description": { "zh": "…", "en": "…" }
}
```

4. 提交 PR(标题:`[插件] <id> <名称>`),通过格式校验与人工审核后合并;
5. 客户端市场稍后即可搜到并一键安装。更新版本 = 递增 `version`、替换 zip、更新条目,再发一个 PR。

## 8. 注意事项

- `id` 一经发布不可更改(客户端以它做安装/查重/卸载);
- 插件 DLL 内**不要**重复打包 Viora.Core / Viora.PluginSdk(宿主共享,重复会引入边界问题);
- 阶段代码要可取消、控制内存(参考内置风格的并行写法);
- 禁止任何联网/遥测行为,违反直接下架。
