# 05 · 设置与本地化

> 设置全部即时保存到 `settings.json`(用户数据目录;便携模式跟随 exe)。

## 通用设置

| 设置 | 说明 |
|---|---|
| 启动时最大化 | 启动即最大化窗口 |
| 界面语言 | 中文(简体)/ English,也可顶栏切换;切换后询问立即重启(少数文案重启才完整生效) |
| 界面字体 | 列出本机全部字体,选择即时全局生效;所选字体自动拼接微软雅黑/Segoe UI **保底链**,缺字形也不缺字;留空 = 默认 |
| 导入大小上限 (MB) | 单张图片导入上限,0 = 不限;风格化页空态文案随设置显示 |
| 日志目录(调试组) | 显示实际路径,可更改(重启生效)、直达文件夹、恢复默认 |
| 日志级别 / 开发者模式 | 控制日志详细度;开发者模式在报错弹窗展示完整堆栈 |
| 日志路径脱敏 | 记录日志时隐藏本地路径隐私段 |

## 外观

| 设置 | 说明 |
|---|---|
| 配色方案 | 10 套内置(石墨/深海/森林/梅紫/落日/午夜/纸白/暖沙/樱花/薄荷),点击即时切换 |
| 自定义主题 | 以当前主题五色(背景/表面/强调色/主色容器/主文本)为起点,色块点击弹系统取色器,保存为 JSON 持久化主题,可删除 |
| 界面缩放 | 80%–120% 档位,主体界面与字号整体缩放,顶栏不缩放,即时生效 |

## 性能

| 设置 | 说明 |
|---|---|
| 交互预览质量 | 拖参数时低清快跑、松手全质量 |
| 预览最大边长 | 256–4096 |
| 导出最大边长 | 1024–16384 |
| 导出格式 | PNG / JPEG / BMP / TIFF / GIF / WebP(WebP 需系统 WebP 编解码扩展) |
| JPEG 质量 | 1–100%,仅对 JPEG 生效 |

## 插件管理

| 设置 | 说明 |
|---|---|
| 启用插件 | 总开关,关闭后启动不加载任何插件(重启生效) |
| 已安装插件列表 | 每个插件单独启用/禁用,失败自动回滚;安装与卸载请到插件市场 |

## 快捷键

| 快捷键 | 默认 | 说明 |
|---|---|---|
| 开始风格化 | Ctrl+Enter | 风格化页运行 |
| 打开图片 | Ctrl+O | 唤起导入文件框 |
| 切换到风格化/我的作品/插件市场/设置 | Ctrl+1 / 2 / 3 / 4 | 主导航 |

点击组合键胶囊开始录制:按新组合完成、Esc 取消、Delete 清除;冲突会提示占用者;「恢复默认」一键重置。**新增快捷键**:在 `HotkeyService.Defaults` 注册表加一条定义即可,设置页自动出现录制行。

## 本地化与外置语言包

- 内置:简体中文(`zh-Hans.json`)、English(`en.json`),嵌入程序集,缺键自动回落英文;
- **外置包(方案 C)**:程序旁 `languages\` 文件夹,放入 `<语言码>.json`(如 `fr.json`)重启即出现在语言下拉;
  - `_template.json` 是 en.json 全部键的空值模板,翻译它即可;
  - `Language.DisplayName` 键决定下拉框显示名;
  - 外置键**覆盖**内置键,缺失键回落英文;损坏文件自动跳过;
  - 也欢迎把新语言 PR 进主仓库,随版本内置给所有用户。
- 插件可自带文案:初始化时 `context.RegisterStrings(...)`(键格式 `lang::Key`)。

## 数据都在哪

| 数据 | 位置 |
|---|---|
| 插件 | `<exe>\plugins\<插件id>\` |
| 外置语言包 | `<exe>\languages\` |
| 作品库 | 用户数据目录 `works\`(可在设置自定义) |
| 设置 | 用户数据目录 `settings.json` |
| 日志 | 用户数据目录 `logs\`(可自定义) |
| 自定义主题 | 用户数据目录 `themes\` |

> 便携模式(exe 旁放 `portable.marker`)下,除插件与语言包外,以上全部跟随程序目录。
