# Viora 功能清单(供界面设计参考)

> 本文面向界面/交互设计(可交给 ChatGPT 等工具做重设计参考),完整描述 Viora 当前版本的**全部功能、页面结构、数据形态与交互行为**,不涉及代码实现细节。
> 技术形态:Windows 桌面应用(WPF,.NET 8),暗色主题,圆角胶囊设计语言,中/英双语。

---

## 1. 应用概览

- **定位**:本地图片风格化工具——用"插件化艺术风格"把普通照片转换成水彩、油画、像素画等 55 种艺术风格,并管理生成的作品。
- **口号**:「Viora,用想象力,让图片更有温度」/ 风格化副标题「一键生成多种风格」。
- **主结构**:左侧固定导航栏 + 右侧内容区,无边框自定义窗口(自绘最小化/最大化/关闭按钮、顶部栏)。
- **导航项(带图标+主/副标题)**:
  - 核心区:风格化、我的作品、插件市场、设置
  - 辅助区:关于、帮助、反馈
- **当前状态**:前三个核心页面功能完整;**设置/关于/帮助/反馈目前是占位页**(尚未实现)。
- **吉祥物**:左下角有一个二次元看板娘形象(装饰),部分页面右下角有蝴蝶/小精灵装饰元素。

## 2. 通用设计语言

- 暗色紫罗兰色系(深底 + 品牌紫渐变 + 霓虹描边光晕),圆角 12~14px 卡片、胶囊按钮。
- 卡片选中态:品牌紫描边 + 紫色辉光阴影。
- 标签(分类/技能 Tag)为小号胶囊药丸样式。
- 图标全部为矢量几何库(约几十个线性图标:星、垃圾桶、下载、放大镜、拼图、魔杖、云下载、地球、用户、省略号等)。
- 语言:中文(zh-Hans)/ 英文(en),顶栏地球按钮切换,全部文案走本地化键。
- 主题色走 DynamicResource(理论上支持换肤,设置页未实装)。

## 3. 页面一:风格化(核心创作页)

**用途**:选一张图 → 选一个风格 → 调参数 → 生成 → 对比/导出。

### 3.1 风格选择
- 风格卡片网格(每个风格一张卡,显示名称、分类),风格总数 55 个,**全部由插件提供**(客户端零内置,装多少显示多少)。
- 分类与插件市场共用同一套 20 个官方大类(动漫、插画、油画、水彩、素描、版画、像素艺术、复古胶片、3D 立体、赛博朋克、霓虹灯光、手工艺、纸艺纸雕、拼贴混合、摄影暗房、玻璃马赛克、金属质感、光影粒子、国风传统、实验创意)。

### 3.2 图片导入
- 导入按钮(文件选择器,支持 png/jpg/jpeg/bmp/gif/tif/tiff/webp)、可加载内置示例样张。
- 单图工作区 + **批量队列**两种模式。

### 3.3 参数与运行
- 每个风格暴露 0~N 个可调参数(滑杆/开关/枚举选项三种形态,含默认值、最小/最大/步长),参数面板可一键重置。
- 「运行」执行风格化,带进度与取消;失败可「重试」。
- 质量档位:预览质量(快)/ 全质量(慢)。
- 结果自动存入"我的作品"(作品库)。

### 3.4 对比查看
- 原图/结果对比查看器:支持 **分屏滑杆对比**(拖动分割线)、缩放(放大/缩小/适应)、多结果切换(上/下一个、删除当前)。

### 3.5 批量处理
- 队列管理:多选加入、移除单项,逐张显示状态(等待/运行中/完成/失败)。
- 批量进度条 + 进度文本 + 取消;完成后逐张自动入库。

### 3.6 历史记录
- 最近 30 条作品缩略图,点击可回打开/重跑。

## 4. 页面二:我的作品

**用途**:管理所有风格化生成的作品。

- **两种视图**:卡片网格视图 / 列表视图(可切换)。
- 作品卡片:封面缩略图、标题(可双击**行内编辑**)、生成时间、风格徽标、选中高亮。
- 卡片快捷操作(悬停/常显):**收藏**(星标,点亮变金色)、**导出**、**更多(…)**。
- **更多菜单**(深色上下文菜单):重新生成 / 创建副本 / 打开所在文件夹 / 收藏(取消收藏)/ 删除。
- **右侧详情面板**(选中作品后):
  - 大图预览、风格徽标;
  - 时间行 + 收藏按钮 + 更多按钮(与卡片同一套菜单);
  - 作品信息行(名称、风格、尺寸、生成时间等键值对);
  - 支持从详情跳回风格化页(继续创作)。
- 空状态引导(无作品时引导去风格化)。

## 5. 页面三:插件市场

**用途**:浏览/搜索/安装/卸载风格插件。**插件与客户端完全分离**:客户端本体零内置插件,全部从官方 GitHub 仓库(huyangpahuo/Viora-plugins)真实下载;未来接入作者自己的后端数据库,目录结构不变。

### 5.1 布局
- 顶部 Hero 横幅(标题 + 副标题 + 三个卖点徽标:丰富的风格类型 / 持续更新 / 一键安装)。
- 左侧主区:分类标签行 + 搜索框 + 插件卡片网格(3×3) + 分页器 + 空状态。
- 右侧面板(420px):插件详情 或 "作者全部插件"列表,顶部胶囊开关切换。

### 5.2 分类标签行
- 标签:全部、我的插件、热门、然后 20 个官方分类;**鼠标滚轮可横向滚动**。
- 「全部」= 全部插件;「热门」= 按安装量排序;「我的插件」= 已安装的。

### 5.3 搜索
- 实时过滤(输入即搜),覆盖:插件名称 / 作者 / 标签 / 描述。与分类标签叠加生效。

### 5.4 插件卡片(小卡)
- 封面图(无图时回退品牌渐变 + 图标)、左上"推荐"徽标位、右上"已安装"徽标;
- 名称、**作者行(点击作者名 → 打开该插件的 GitHub 仓库地址)** + 认证勾;
- 标签药丸(分类 + 作者自配标签,数量不定);
- 评分(★4.x)+ 安装量(伪数据,未来接网站统计);
- 右下角安装按钮(三态:安装 / 安装中 / 已安装,带安装中转圈)。

### 5.5 详情面板(右)
- 大预览图 + "已安装"角标;
- 名称 / 作者(点击跳仓库)/ 认证 / 评分与评价数(伪数据);
- 标签药丸行;
- 描述文字;
- 元信息行:**版本(目录中的版本号)、大小(包真实体积,MB/KB)、更新时间(包的最后更新日期)**——选中卡片后异步加载,网络不可用显示占位;
- 操作按钮:大号「安装」(已安装态变为玻璃质感"已安装")+「卸载」(垃圾桶图标,带确认弹窗);
- **效果预览**:原图 | 风格化后 两块图。已安装的插件会用内置样张**真实渲染该插件风格**作为"风格化后"(后台渲染 + 缓存);未安装时显示封面图占位;
- 插件信息:开发者 / 分类 / 支持格式(JPG/PNG/WEBP)/ 适用版本;
- 可展开「更新日志」(暂为占位数据)。

### 5.6 "作者全部插件"面板
- 详情面板顶部胶囊开关「作者全部插件」点开:列出**当前所选插件作者的全部插件**(名称 + 作者行 + 已安装勾标);
- **与搜索框联动**:搜索词实时过滤该列表;头部显示"作者名 · N 个插件";
- 点击列表项 → 选中该插件回到详情。

### 5.7 安装 / 卸载行为
- 安装:从官方仓库下载 zip(真实网络下载,失败提示"离线")→ 解压到**程序目录旁的 plugins 文件夹** → 立即生效(风格出现在风格化页);
- 卸载:确认弹窗 → 真删除插件文件夹(文件被占用时改名隔离,下次启动自动清理),永不复活;
- 用户也可以直接在资源管理器里增删 plugins 文件夹内容,效果等同安装/卸载;
- 全新安装 = 零插件,风格化页为空,引导用户去市场安装。

## 9. 插件系统(为设计理解的背景知识)

- 一个插件 = 一个文件夹:`plugin.json`(清单:id、名称、版本、入口 DLL、入口类、能力声明)+ 编译好的 DLL;市场里的 zip 即此文件夹的压缩包。
- 插件能力:注册**风格预设**(出现在风格化页)、注册导出格式、注册界面文案;未来:设置页。
- 第三方开发者流程:写一个继承插件基座的类(约 30 行)+ 清单 → 打 zip → 向官方仓库提交 PR(packages 放 zip + registry.json 加条目,可选填 repository 仓库地址和 tags 标签)→ 审核合并后市场可见。
- 安装区路径:exe 旁 `plugins\` 文件夹(便携可见;目录不可写时自动回退用户数据目录)。
