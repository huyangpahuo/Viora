# 01 · 功能总览

> 对应版本:v1.0.0。所有界面文案支持简体中文 / English。

## 风格化(核心创作页)

| 功能 | 说明 |
|---|---|
| 风格选择 | 风格卡片网格 + 分类标签(全部/热门/20 个官方分类),标签行支持滚轮横滚与横向滚动条 |
| 图片导入 | 文件选择器 / 拖拽,支持 PNG/JPEG/BMP/GIF/TIFF/WebP;单张大小上限可在设置调整(默认 10MB,0 = 不限) |
| 参数调节 | 每个风格暴露自己的参数(滑杆等),拖动时以预览质量实时重跑,松手出全质量;一键重置 |
| 运行 | 进度显示、取消、失败重试;结果自动存入"我的作品" |
| 对比查看 | 原图/结果分屏(拖动分割线)· 缩放(放大/缩小/适应)· 多结果切换 |
| 批量处理 | 多选入队、逐张状态(等待/运行/完成/失败)、进度与取消;缩略图可点击在主预览区查看 |
| 历史记录 | 最近 30 条作品缩略,一键回开 |

## 我的作品

| 功能 | 说明 |
|---|---|
| 双视图 | 卡片网格 / 列表,网格居中排布 |
| 搜索筛选 | 按名称/风格/标签实时搜索;标签页:全部/最近创作/收藏/导出记录;排序:最新/最早/名称/大小 |
| 收藏 | 卡片与详情面板星标即时点亮,收藏页实时增减 |
| 行内重命名 | 双击标题直接编辑 |
| 操作 | 重新生成(回到风格化并带入参数)· 导出 · 创建副本 · 删除 · 打开所在文件夹 |
| 详情面板 | 大图预览、作品信息(原图名称/风格/时间/大小/尺寸)、使用的参数(按当前语言显示) |

## 插件市场

| 功能 | 说明 |
|---|---|
| 目录 | 官方 GitHub 仓库 55 个风格插件;启动时拉取最新目录,离线回退内置快照 |
| 浏览 | 标签页(全部/我的插件/热门/20 分类)+ 实时搜索(名称/作者/标签/描述),支持叠加 |
| 插件卡片 | 封面、名称、作者(点击跳转插件仓库)、标签、评分与安装量(占位数据)、安装按钮三态 |
| 详情面板 | 大预览、版本/包大小/更新时间(真实数据)、描述、安装/卸载按钮、效果预览(已安装插件用真实管线渲染样张) |
| 作者全部插件 | 右侧面板列出该作者全部插件,与搜索框联动,点击跳详情 |
| 安装 | 从 GitHub raw 下载 zip → 解压到程序旁 `plugins` 文件夹 → 立即生效;本地镜像作离线兜底 |
| 卸载 | 确认后真删除文件夹;文件被占用时改名隔离、下次启动清理;也可直接在资源管理器手动删 |
| 社区入口 | QQ 群 / Discord / Telegram / GitHub(关于与反馈页同样入口) |

## 全局

| 功能 | 说明 |
|---|---|
| 语言 | 简体中文 / English,顶栏即点即换;切换时询问是否重启以完整生效 |
| 字体 | 设置中可选本机任意字体,全局生效并带中文字体保底链 |
| 界面缩放 | 80%/90%/100%/110%/120% 档位选择块,即时生效(顶栏不缩放) |
| 主题 | 10 套配色方案即时切换 + 自定义主题(五色编辑器,保存后可复用/删除) |
| 快捷键 | 可视化录制修改,冲突检测;默认:Ctrl+Enter 运行、Ctrl+O 打开图片、Ctrl+1~4 切换页面 |
| 检查更新 | 设置 → 关于,对比 GitHub Releases 最新版本号与更新说明 |
| 便携模式 | exe 旁放 `portable.marker`,所有数据跟随程序目录 |
| 关于/帮助/反馈 | 软件与插件生态介绍、FAQ、诊断信息复制、日志文件夹直达、社区入口 |
